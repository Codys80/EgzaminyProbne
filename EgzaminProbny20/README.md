# EgzaminProbny20

Ten folder zawiera wszystkie projekty powiązane z egzaminem nr 20.  
Projekty są oparte na arkuszu z sesji egzaminacyjnej z dnia 20.01.2026


## Zawartość

- ConsoleApp/ – aplikacja konsolowa w C#  
- MobileApp/ – aplikacja mobilna (MAUI) 
- Dokumentacja/Git - z uwagi na charakterystyke rozwiązywania przeze mnie arkuszy ta część nie została uwzględniona
> Każdy podfolder zawiera odpowiedni kod źródłowy dla danego typu projektu.
